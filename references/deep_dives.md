# Deep-dive action specifications

Read this file only when the user has selected a follow-up action. Execute only the matching section. Every output keeps the hard rules and the Verification standard from SKILL.md (neutral language, source citations, no invented numbers, "verified" only with the full evidence block) and ends with the disclaimer: "This is general information only and not financial advice. For personal guidance, please talk to a licensed professional."

## Make deeper analysis

The full fundamental review. Research beyond the first pass (additional filings, 5-year history, peers). Sections:

1. **Business model breakdown** — how it makes money, key segments, geographic exposure, customer type, main growth drivers.
2. **Sector classification** — packet used, why it fits, mixed-business segments needing separate treatment (sum-of-the-parts note).
3. **Peer group** — 5–10 direct peers with one-line rationale each; reject lazy sector-label groups (the Core Framework's peer-group page has the criteria).
4. **Five-year financial trend** — table of sector-relevant metrics (not generic ones), yearly.
5. **Sector-specific metric review** — table: current value | 5-year history | peer median/range | P/W/N rating | data confidence. Upgrade any provisional first-pass ratings ONLY where the underlying number meets the Verification standard (label read in the source document); otherwise keep the rating and say why.
6. **Balance sheet & liquidity** — sector-appropriate: banks CET1/deposits/LDR/credit; REITs debt/EBITDAre, coverage, maturities, AFFO payout; utilities FFO/debt, coverage, allowed ROE, regulatory lag; industrials net debt/EBITDA, FCF, cyclicality; SaaS cash runway if unprofitable, dilution, FCF margin.
7. **Earnings quality** — cash conversion, GAAP vs adjusted gap, recurring add-backs, working-capital effects, acquired vs organic growth, revenue-recognition risks, margin-improvement quality.
8. **Geographic/currency/political risk** — revenue vs profit vs asset geography, currency mismatches, debt currency, regulatory/political exposure, tariffs/sanctions/tax.
9. **Valuation** — the sector's method only; vs peers and own 5-year history; what the current price appears to assume; key valuation risks.
10. **Risks and catalysts** — separate fundamental / valuation / balance-sheet / sector-macro risks; potential catalysts; what data would change the conclusion.
11. **Source list** — primary vs secondary vs market-data; list unverified/estimated items.
12. **Final neutral research conclusion** — one of the four labels, main reason, top 3 metrics to monitor, unresolved data gaps. Recompute the weighted score and state if it changed — with the verification evidence block for any metric that moved a rating.

## Verify missing data

Focus exclusively on items the first pass marked missing, estimated, or needs-verification. For each metric, produce the full verification evidence block from SKILL.md's Verification standard: metric name | exact value | exact source document | exact page/table/section | short quote showing the label next to the value | why the label matches the guide's definition | rating/score impact. The quote requirement is non-negotiable — fetch and read the actual filing text (not search summaries) before marking anything verified. Apply the label-match rule: a value may only be attributed to a metric whose label it actually carries. If the document can't be read after applying the retrieval-resilience ladder in SKILL.md, or the metric isn't disclosed, report "not directly disclosed / needs verification," explain which sources were checked, keep the confidence penalty, and leave the pillar rating unchanged. Finish with the updated score and confidence level, stating explicitly which items moved and which didn't.

## Compare vs peers

A focused peer table — no other sections. 4–8 genuine peers: company | ticker | why it's a relevant peer | the sector's 2–3 key operating metrics | the sector's valuation metric | a growth/return metric | a balance-sheet/risk metric | comparability notes (size, mix, geography caveats). Then 3–5 sentences: where the company ranks, whether its premium/discount looks explained by fundamentals, and which provisional first-pass ratings this changes (restate the updated score if any rating moves).

## Deep dive: valuation

Valuation only. The sector's correct methods; current multiples vs own 5-year range and vs peers; the growth/return profile that justifies or contradicts the multiple; **what the current valuation appears to assume** (reverse-engineer: growth rate, margin, or ROE needed to defend the price — label as illustrative); key valuation risks including the cyclical peak-earnings trap where relevant; quote external analyst consensus only with source. No recommendation.

## Deep dive: risks

Risks only. All flags graded Severe/Moderate/Minor with evidence and verification status; probability/impact framing where honest (avoid false precision); for each material risk: what would confirm it, what would reduce it, and the specific metric to monitor with its current reading. Include the override-rule implication: which single development would cap the score at 50%.

## Deep dive: sector-specific weak area

Take the weakest pillar or the sector's characteristic vulnerability identified in the first pass and go deep on only that: all related metrics from the packet with formulas applied, the 5-year trend, peer context if available, the verification status of every input, and what reading would upgrade or downgrade the pillar rating. Examples of scope — banks: credit quality (NPL vintages, charge-off trend, coverage, concentrations) or capital (CET1 vs requirement, buffers) or deposits/funding (mix, cost, flight risk); SaaS: retention/Rule of 40 decomposition or SBC/dilution trajectory; REITs: AFFO coverage and the maturity ladder or NAV/implied cap rate build; energy: breakeven decomposition (field vs corporate vs dividend) or reserve life and replacement.
